An enterprise-grade, high-performance web platform cloned and elevated from [eurogoldrefinery.com](https://eurogoldrefinery.com/) and built for [eurogolddealers.com](https://eurogolddealers.com/).

## 🏛️ Strategic Institutional Partnerships

- **Bank of Uganda (BoU)**: Designated supplier and refinery under the Central Bank's Domestic Gold Purchase Reserve Program.
- **Ministry of Energy & Mineral Development**: Operating in full alignment with the Directorate of Geological Survey and Mines (DGSM) under the 2022 Mining and Minerals Act.
- **9 DGSM Mineral Licenses & 10 Certifications**: Complete legal licensing for dealing, refining, assaying, smelting, and international export clearing.
- **79.8 km² Yumbe Concession**: Mechanized alluvial and quartz-vein mining asset in Northern Uganda targeting 80kg monthly output.

## 💻 Development & Build

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Navigate to `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
```
The optimized static build will be placed in the `dist/` directory ready for deployment to Vercel, Netlify, Cloudflare Pages, or AWS S3 / CloudFront.
